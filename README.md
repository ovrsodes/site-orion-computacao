# Landing Page - Orion Aerospace Design
Esta é uma landing page desenvolvida para o desafio trainee da Orion (UTFPR PG), feita com HTML e Tailwind CSS.

# Como começar
Clone o repositório e, em seguida, abra o arquivo index.html em um navegador para visualizar a página.
